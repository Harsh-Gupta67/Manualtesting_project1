## 📌 Project Overview

This repository contains a comprehensive **Manual Testing Project** for a Lift (Elevator) Management System. The project demonstrates the complete software testing process, including requirement analysis, test planning, test case design, defect reporting, requirement traceability, and test summary reporting.

The objective of this project is to validate the functionality, safety, reliability, usability, and performance of a lift system using industry-standard QA documentation and testing practices.

---

## 🎯 Objectives

- Validate all major functionalities of the Lift Management System.
- Design comprehensive manual test cases covering positive, negative, boundary, and edge scenarios.
- Apply software testing techniques used in real-world QA projects.
- Prepare professional QA documentation following the Software Testing Life Cycle (STLC).
